Get DraconDex

One app, three ways to run it — install it on Windows, sideload the Android APK, or open it in a browser and keep it there as a PWA. Each one is free, works offline, and keeps your worlds on your own device; there is no account anywhere. The Windows builds are first, the browser build closes this section, and Android has a section of its own further down.

In the browser

Or take it with nothing installed

DraconDex also runs as a web app, and installs from the browser like any other PWA — which is how you get it on macOS, Linux, a Chromebook, or an iPhone. It is the real app, not a demo: the desktop lane runs the Electron front-end's own renderer and data layer in the page, and the mobile lane is the same Flutter build that ships as the APK. A router picks the lane that fits your device.

Open the web app How it is built

Where the data goes

Into the browser's own storage on that device — there is no account and no server. Which also means it belongs to that browser: clearing site data or opening a private window starts you from empty. Export a .ddx file for anything you want to keep; the desktop app opens it directly.

What a page cannot do

Plugins (separate windows with filesystem access), reveal-in-folder and other OS handoffs, keeping an imported file linked to its path on disk, and the installer-based update notice. Each says so rather than failing quietly. Everything else is the whole app, offline after the first load.

Build Installs? Your data lives in Best for

DraconDex-Portable-<version>.exe No — one file, just run it novel-manager-data next to the exe A quick try, or a locked-down machine
DraconDex-<version>-win-x64.zip No — unzip and run DraconDex.exe novel-manager-data inside the folder USB sticks; the whole project travels with the folder
The portable builds are around 200–220 MB. That is Electron — the app bundles its own browser engine so it never needs a runtime installed, and never needs the network.
Verify

Check what you downloaded

Every release ships a checksums-sha256.txt covering everything attached to it — the three Windows builds, or the four APKs. Compare before you run anything. 

# PowerShell
Get-FileHash .\DraconDex-Setup-<version>.exe -Algorithm SHA256

# then compare against the matching line in checksums-sha256.txt
The builds are not code-signed. Windows SmartScreen will warn you the first time you run one. That warning is expected for an unsigned open-source build — checking the SHA-256 above is the real verification.
Android

The Android app

A Flutter build with its own release line — flutter-v* tags, versioned independently of the desktop app. It shares the desktop app's SQLite schema, so a world can move between the two, but it is developed separately and is still behind on features.

Not sure which one? Take arm64-v8a — it fits every phone and tablet shipped in the last several years. The universal APK carries all three architectures at roughly twice the size, and is the safe answer if the ABI split ever installs the wrong one.

Installing it

Open the downloaded .apk and allow installs from whichever app you downloaded it with — Android asks once, per source. DraconDex is not on Google Play, so this is a sideload. Once it is installed, the app's own update check can install later releases over the top.

Build it yourself

Flutter SDK 3.44.4+ and the Android toolchain: 

cd flutter
flutter pub get
flutter build apk --release --split-per-abi
Coming from 2.3.0–2.8.0? Uninstall first. Those builds were each signed with a throwaway key, so Android refuses to update over them. Export your data, uninstall, then install 2.8.1 or newer — every release from 2.8.1 on is signed with the same permanent certificate (CN=DraconDex, O=ZYDRAXYL, C=TH, SHA-256 6b1b62e9…c2dc97e8) and updates in place from there on.

To move a world across: Export it from the desktop app, copy the .ddx file to the phone and rename it to .db (the Android file picker filters on that extension), then use Settings → Import Database. Both sides use the same schema, and importing merges rather than replaces.
