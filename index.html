Your whole world, kept on your own disk.

DraconDex is a desktop app for organizing the data behind a story — characters, places, timelines, relationships, and free-form notes — for novelists, story-game designers, and D&D DMs.

What it does

Built for the messy middle of world-building

Everything lives in local SQLite files. Nothing leaves your machine unless you set up a backup or a sync yourself — with your own credentials — and the whole project folder can travel on a flash drive.

Two module systems, side by side

Seven fixed legacy modules — Director, Navigator, Hero, Writer, Scribe, Sage, Artisan — alongside the v3 "Nexus nest": an unlimited tree of modules you build yourself.

Wikilinks between notes

Write [[a link]] anywhere in your notes and get backlinks across every piece of content in the project.

Maps, timelines, canvases

Dialogue graphs, sketching and diagramming surfaces built on vendored D3 and Konva — bundled with the app, so they work with the network off.

18 languages, 3 themes

Thai by default, with English, Japanese, Korean, Chinese, Vietnamese, Indonesian and eleven more — plus midnight, daylight and moonlight themes.

Portable by design

The portable build keeps your data next to the executable. Copy the folder to a USB stick and your project comes with it.

Backups you own

Export the whole database, a single Nexus, or one module subtree to a file. Optional Google Drive backup uses the drive.appdata scope and your own OAuth client — no DraconDex server in the loop.

The v3 module tree

Fifteen kinds, nested however you want

Instead of a fixed set of screens, DraconDex v3 lets you grow a tree of modules. Each node picks one of fifteen kinds, and the kind decides what the module can do — collect records, draw a map, track a timeline, sketch, or write prose.

Plugins

4 official plugins, installed from a link

Paste a repository link into Settings → Plugins. DraconDex shows you exactly which files it will fetch, which tables it will create and which hosts it may talk to — then runs the plugin in a separate sandboxed window with no access to your main data.

Platforms

Where it runs

Windows desktop

The main app, built on Electron. Ships three ways every release: an NSIS installer, a single-file portable .exe, and a zipped portable folder.

Downloads →

Android signed APKs

A Flutter build, released on its own tags: four signed APKs — one per architecture plus a universal one — attached to every release. Same SQLite schema as the desktop app, developed independently, still behind it on features.

Get the APK →

In the browser

Both front-ends built for the web and installable as a PWA — the desktop one for big screens, the Flutter one for touch. Your data stays in the browser's own storage; no account, no server.
